# 游戏卡片悬停预览说明

## 关键模块作用

- `catalog.html` 与 `index.html` 中的 `data-preview` 保存每款游戏的短视频路径。
- 鼠标停留约 650 毫秒后，页面才会加载对应视频。
- 鼠标移开后，视频会暂停、删除资源地址并释放网络与内存。
- 手机和平板默认不加载悬停视频，避免浪费流量，也避免触摸操作误触。
- 当前所有 `data-preview` 都为空，因此网站不会请求任何预览视频。

## 推荐素材规格

- 格式：优先 WebM，同时可使用 MP4。
- 时长：2–5 秒无缝循环。
- 画面：真实游戏过程，不包含弹窗广告、用户隐私或平台后台。
- 声音：删除音轨；页面会使用 `muted` 静音播放。
- 尺寸：建议 600×600 或 800×800，比例为 1:1；其他比例会居中裁切。
- 文件大小：建议每段控制在 600 KB 以内。

## 为卡片启用预览

1. 将视频放入本目录，例如 `potion-sort.webm`。
2. 打开 `catalog.html`。
3. 找到对应游戏卡片的 `data-preview=""`。
4. 修改为 `data-preview="assets/previews/potion-sort.webm"`。
5. 将相同修改同步到 `index.html`。
6. 保存后在电脑端刷新页面，鼠标停留在卡片上约 1 秒验证效果。

不要把第三方游戏 iframe 直接用作卡片预览。这样会触发广告、音频和大量网络请求，也可能造成错误的广告曝光统计。
